# cnAgentOS — 智能瞭望与智能问数系统

基于 **Python Tornado** 的 B/S 架构智能平台，集成 AI 大模型对话、Web 数据采集、AI 深度内容分析、RBAC 权限管理等能力，支持多数字员工的调度与协作。

---

## 技术栈

- **后端框架**: Tornado (Python)
- **数据库**: SQLite
- **AI 大模型**: OpenAI 兼容 API（DeepSeek 等）
- **前端**: Bootstrap 5 + Font Awesome 5 + jQuery + SSE（Server-Sent Events）
- **运行端口**: `10086`

## 功能模块

### 1. 用户认证系统

- **前台登录/注册**：用户可通过 /user/login 登录、/user/register 注册
- **密码安全**：PBKDF2-SHA256 加盐哈希存储，100,000 次迭代
- **会话管理**：基于 Tornado Secure Cookie 的会话机制
- **角色区分**：管理员从后台登录，普通用户从前台登录，互不冲突
- **默认管理员**：admin / admin888

### 2. 后台管理面板（Admin Panel）

- **管理员登录**：独立的后台登录页面 `/admin/login`
- **控制台 (Dashboard)**：后台首页，展示系统概览
- **用户管理**：
  - 用户列表（分页、搜索）
  - 创建用户（可指定角色）
  - 更新用户（普通用户可改用户名/密码/角色，admin 仅可改密码）
  - 删除用户（支持单个/批量删除，admin 用户受保护）
  - 用户角色分配

### 3. RBAC 权限管理系统

- **功能管理**：
  - 多级功能菜单（父/子级联动）
  - 功能树查看
  - 支持设置图标、URL、排序、启用/禁用
- **角色管理**：
  - 系统角色（超级管理员、普通用户、会员），不可删除/修改编码
  - 自定义角色创建与编辑
- **权限管理**：
  - 按角色分配菜单/功能权限
  - 树状权限勾选界面
  - 一键清除/保存权限配置
- **动态菜单**：根据用户角色权限自动渲染侧边栏菜单

### 4. AI 模型引擎

- **模型管理**：支持多个 OpenAI 兼容大模型（如 DeepSeek）的 CRUD
- **默认模型**：可设置默认 AI 模型
- **对话测试**：内置普通响应和 SSE 流式响应两种对话测试方式
- **Token 统计**：按天统计 Token 消耗量，记录每次调用详情
- **Thinking 模式**：API 调用时启用 `extra_body={"thinking": {"type": "enabled"}}`

### 5. 瞭望采集引擎

- **数据源管理**：
  - 多数据源配置（Web 类型，支持自定义 URL 模板、请求头、Cookie）
  - 支持 `{keyword}` 和 `{pn}` 分页占位符
  - 启用/禁用切换
  - 预置「百度新闻」数据源
- **关键词采集**：
  - 输入关键词 → 多数据源并发采集
  - 多页采集控制
  - 智能 HTML 解析（百度新闻专用解析器 + 通用链接提取器）
  - 结果自动过滤（去重、去除导航链接）
  - 实时调试日志输出

### 6. 数据仓库

- **采集数据管理**：
  - 数据列表（分页，支持按关键词、数据源筛选）
  - 查看数据详情（标题、URL、来源、摘要、采集时间）
  - 单条/批量删除数据
- **深度采集状态追踪**：显示每条数据的深度采集状态（未采集/采集中/已完成/失败）

### 7. AI 深度内容采集

- **单条深度采集**：
  - 抓取目标页面完整 HTML → 提取正文内容（去除脚本/样式/标签）
  - 统计字数、预估阅读时间
  - AI 智能分析：自动生成摘要、提取关键词、分类、情感分析、实体提取
- **批量深度采集**：
  - 选中多条数据批量处理
  - 自动跳过已采集数据，统计成功/失败/跳过数量
- **统计面板**：实时查看深度采集进度、统计数据和操作日志
- **详情查看**：查看深度采集的完整内容、AI 分析结果

### 8. 第三方 API 接口管理

- **接口管理**：增删改查第三方 API 接口
- **字段支持**：名称、编码、URL、请求方法、响应格式、参数说明、示例 URL、QPS 限制、认证 Token、标签
- **搜索筛选**：支持名称/编码关键词搜索和标签筛选
- **预置接口**：
  - 随机网易云音乐
  - 三日天气查询

### 9. 数字员工

- **员工管理**：
  - 两种类型：**AI 型**（关联 AI 模型 + System Prompt）和 **API 型**（关联第三方接口）
  - 别名（@name）作为唯一调度标识
  - 可配置输入参数（参数名、标签、占位符）
- **数字员工对话**：
  - 专用的数字员工对话页面
  - @别名 方式调用，AI 型支持 SSE 流式对话
  - API 型自动拼接参数调用
- **预置员工**：
  - `@川小农`：AI 型文案编写助手，按步骤引导创作专业文案
  - `@天气`：API 型天气查询
  - `@音乐`：API 型随机音乐推荐

### 10. 用户侧智能对话

- **多轮对话**：支持创建/切换/删除对话，历史记录持久化
- **智能意图识别**：
  - 自动识别数据查询意图（匹配关键词：最新、统计、查询等）
  - AI 自动生成 SQL 并执行，返回格式化结果
- **数字员工调用**：通过 @别名 调动数字员工
- **上下文感知**：检测对话上下文，自动延续 @employee 模式
- **SSE 流式输出**：AI 对话实时流式响应
- **支持的查询表**：watch_data（采集数据）、watch_data_detail（深度采集详情）、watch_sources（数据源）

### 11. 智能聊天子系统（IM）

仿微信风格的即时通讯系统，支持私聊、群聊、文件传输，并集成数字员工。

#### 用户侧功能

- **好友管理**：
  - 搜索系统用户、发送好友请求
  - 接受/拒绝好友申请
  - 删除联系人
- **私聊消息**：
  - SSE 实时私聊消息推送
  - 消息轮询与已读状态
  - 2 分钟内消息撤回（右键菜单，系统撤回提示）
- **群聊管理**：
  - 从通讯录多选好友创建群聊（自动生成群名）
  - 群成员管理（邀请新成员）
  - 群名称修改（群资料页编辑，系统消息推送）
  - 退出群聊（群主需先转让群主身份）
  - 解散群聊（仅群主）
- **数字员工集成**：
  - 数字员工以好友/群成员身份出现在通讯录和群聊中
  - @别名 触发对话，AI 型支持多轮上下文
  - API 型自动调用外部接口（如音乐推荐、天气查询）
  - SSE 流式 / 结构化消息推送（图片 + 文本）
- **文件传输**：
  - 私聊/群聊中上传和下载文件
  - 支持图片预览

#### 后台管理功能

- **群管理**：查看所有群列表与成员、解散群聊、禁言管控、发送系统公告
- **文件管理**：统一查看/管理聊天文件、去重存储、文件预览与删除
- **服务器管理**：多聊天服务器配置与管理、启用/禁用切换
- **工具管理**：AI 工具集可视化展示、工具绑定数字员工、启用/禁用管理

## 快速开始

### 环境要求

- Python 3.8+
- pip

### 安装与运行

```bash
# 1. 创建虚拟环境
python -m venv venv

# 2. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动服务
python app.py
```

启动后访问：
- **后台管理**：http://localhost:10086/admin/login（默认 admin/admin888）
- **用户端**：http://localhost:10086/user/login
- **智能聊天**：http://localhost:10086/user/im（登录后）

### 首次使用

1. 登录后台 → 模型引擎 → 配置你的 AI 模型（API Key、Base URL、模型名）
2. 瞭望采集 → 输入关键词采集数据
3. 数据仓库 → 对采集数据进行 AI 深度分析
4. 数字员工 → 创建和管理智能助手
5. 用户侧 → 体验智能对话和数据查询
6. 智能聊天 → 后台管理 → 智能聊天 → 配置聊天服务器、管理与绑定工具
